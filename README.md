# Ola Ride Analytics | SQL & Power BI

## Project Overview
Ola Ride Analytics is a data analytics project focused on analyzing ride bookings, vehicle performance, revenue, cancellations, and customer and driver ratings using SQL and Power BI.

The project uses a 100,000-row booking dataset to explore operational patterns and present business information through an interactive dashboard.

## Tools & Technologies
- SQL — data querying, aggregation, filtering, and analysis
- Microsoft Power BI — interactive dashboard and visual reporting
- Microsoft Excel — dataset storage and inspection

## Business Questions
- How many bookings were successful?
- What is the average ride distance by vehicle type?
- How many rides were cancelled by customers?
- Which customers booked the highest number of rides?
- How many rides were cancelled by drivers for personal or car-related issues?
- What are the maximum and minimum driver ratings for Prime Sedan?
- How many rides used UPI payments?
- What is the average customer rating by vehicle type?
- What is the total booking value of successful rides?
- What are the reasons for incomplete rides?

## Power BI Dashboard
The dashboard contains five sections:
1. Overall
2. Vehicle Type
3. Revenue
4. Cancellation
5. Ratings
